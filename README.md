# Photography Portfolio

Personal photography portfolio showcasing wildlife, portraits, travel, automotive, and pet photography.

## Features
- Hero image carousel with auto-advance
- Horizontal drag-to-scroll image gallery
- Fullscreen lightbox with keyboard navigation
- Dynamic gallery pages loaded from JSON
- Print shop with Stripe checkout integration
- Contact form with EmailJS
- Minimap scroll indicator on About page
- Loading screen with progress percentage
- Responsive design

## Pages
- Home (portfolio overview + prints section)
- Gallery (dynamic, loads from JSON data)
- About (with scroll minimap)
- Contact (EmailJS integration)
- Print detail pages (Stripe checkout)

## Built with
- HTML
- CSS
- Vanilla JavaScript
- EmailJS (contact form)
- Stripe (print purchases)
